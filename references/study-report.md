# 研究输出核对与逐年报告

分析器生成 report.json 和 signals.csv 后，再用汇总工具检查两份文件是否一致。它不会重新拟合模型、挑选参数或修补输入，也不能证明文件来自哪个平台或数据商。

## 先跑合成示例

先按 README 生成示例分析结果，再在 Skill 目录运行下面的命令。

```powershell
python scripts/summarize_study.py --report outputs/example-first-run/report.json --signals outputs/example-first-run/signals.csv --plan examples/synthetic/reporting-plan.json --output outputs/example-summary
```

输出目录必须尚不存在。成功后会有五份文件。

| 文件 | 内容 |
|---|---|
| summary.json | 输入指纹、报告计划、逐年指标、来源计数及配对区间 |
| yearly.csv | 五方案逐年表现，每年分别列出 1、1.5、2 倍费用 |
| source_reuse.csv | 各方案实际匹配的外盘与 FX 来源，保留文本编号、复用次数及信息年龄 |
| paired_intervals.csv | 对齐方案相对两个国内基线的每窗口净收益差及描述性区间 |
| REPORT.md | 输入指纹、报告计划、年度汇总与限制说明 |

示例计划包括 2024、2025 两年。合成输入只覆盖 2024 年的一小段，2025 年会显示零窗口、空覆盖率和未计算收益。零窗口年不填成零收益年。示例日期包含周末，不能用来验证交易日历。

## 正式研究先写报告计划

下面是演示计划的完整结构。

```json
{
  "evaluation_years": [2024, 2025],
  "report_timezone": "Asia/Shanghai",
  "bootstrap_block_windows": [10, 20, 40],
  "bootstrap_repeats": 1000,
  "seed": 42
}
```

正式研究须按确认的训练与保留范围填写年份，将计划、代码和输入版本一并冻结，然后才评价保留样本。演示年份不能代替已经确认的研究年份。年份须升序连续，不得排除已有评价窗口，或省掉配置范围内没有窗口的整年。按入场时刻在指定时区中的年份分组，费用和收益都保留原分析器的逐窗口开平口径。

计划只接受示例中的五个字段。年份限 1900 至 2200，最多连续 100 年；区块列表最多 10 个长度，每个为 1 至 10000 的整数，按升序填写且不能重复。重抽样次数限 100 至 10000，随机种子限 0 至 4294967295，布尔值不算整数。时区须能被 Python 识别。

训练截止时刻若处于报告时区的 12 月 31 日 23 时 59 分，且该年没有保留窗口，可以从次年开始列报告年份。其他截止时刻按所在年份保留空年，避免省掉范围内没有数据的年份。

工具会核对五个方案的国内窗口、标签和时刻，重算一倍费用明细与三档费用汇总。窗口重复、方案缺行、收益公式不符、来源身份矛盾或指标不一致时停止，不会自行修好后继续。核对只能发现输入内部的矛盾；两份文件一同被篡改、来源失真或漏掉真实交易日，仍需原始文件与平台记录来判断。

## 来源复用与区间怎么读

来源复用只统计匹配成功的输入。没有匹配的诊断候选不计入使用次数，国内基线也不列外盘来源。同一外盘观测供四个国内窗口使用，会计为四次使用、一个来源编号。一个窗口即使最终仓位为零，也可能已用到该信息。来源表是模型输入记录，不是成交记录。

对于匹配成功、实际进入模型的来源，编号与可用时刻在同一来源类型内须一致，来源数值须为有限数。同刻多个编号会使去重统计失真，工具会拒绝。未匹配行中的诊断候选不作同等完整性认证，也不计入来源使用统计。查看 CSV 时请将编号列按文本打开，避免表格软件去掉前导零或改变长整数。

额外滞后方案从第二个保留窗口起，对匹配成功的滞后行逐项核对实际使用的来源是否等于前一个国内窗口的对齐候选。第一个保留窗口的前驱可能在训练期或未导出的跨界窗口中，没有包含在 signals.csv 中，必须回到原始输入和分析器执行记录核实。此项检查不重新拟合模型，也不能单靠预测值证明模型确实使用了这些来源。

时间错位安慰剂会核对外盘来源严格晚于决策时刻且未超出允许间隔，但只凭导出的明细无法确认它确为原始数据中最近的一条未来观测。此项仍需原始来源序列与分析器记录。

共同匹配参照列 aligned_event_id、aligned_fx_id、external_available_at、fx_available_at 不参与汇总核验；各方案的实际来源以 used_ 开头的字段为准。来源复用按方案分别计算，不把不同方案的重复研究使用次数解释成新增独立观测。

区间计算先逐窗口求“对齐方案净收益减国内基线净收益”，保留所有合格窗口，包括零仓位窗口。再从这条配对差值序列中抽取连续区块，拼回原样本长度，记录重抽样均值的 2.5% 和 97.5% 分位。两个国内基线分别比较，三档费用分别计算。

mean_difference、ci_low、ci_high 的单位都是每窗口收益率差，不能当成累计收益差。区块长于窗口数时区间为空，不会自动缩短区块；可用完整区块少于五个时标为 few_blocks_descriptive_only。固定种子便于复跑，不增加样本信息量。

同样区块长度的各项比较共用随机抽样序列，区间之间有关联，不能当成独立重复验证。yearly.csv 中的 sharpe_per_252_windows 按 252 个窗口缩放；只有窗口安排确实对应交易日时，才可能具有通常的日频年化解释。本工具不认证这个条件。

请直接使用分析器保存的原始输出，不要先用表格软件四舍五入。同源数值采用严格一致性核验，精度不同可能被拒绝。明细行可以重新排序，工具会按入场时刻恢复顺序。

运行前先冻结三份输入，并停止其他程序写入。工具对每份文件读到的字节计算指纹，但不能把三个文件锁成同一瞬间的版本。若写报告途中失败，输出目录可能只留下部分文件；保留失败目录，换一个新目录重跑，五份文件齐全且命令成功后再使用结果。

这些区间仅描述给定样本，不是因果证明、经多重比较修正的检验或交易建议。窗口区块也不保证重复使用的外盘消息已相互独立，不能消除历史选题与方案选择带来的偏差。

## 仍需另外完成的验证

覆盖率的分母只是提供给程序的国内窗口，没有独立认证交易所日历。原始行情、授权、历史可用时刻和国内首个可交易时点仍需逐项留证。当前工具始终输出 executable=false，市场来源、日历与平台执行的独立认证也始终为 false。

ridge 或发布等待期的敏感性分析需要另行冻结输入并实际运行模型，本工具不代做这些实验。QuantStudio 的真实市场执行和负责人验收记录也要另外保存；合成示例与本地检查不能补齐这些证据。
