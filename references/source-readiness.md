# 数据够不够做这项研究

数据授权和信息时点是两道不同的检查。接口成功返回数值，只能说明该次查询可用，不能证明数值在历史决策时刻已经发布。

本包现按研究工具交付。下文关于活动难度与负责人确认的记录仅涉及正式申报，不是运行条件；允许披露假设后进行条件性回放，禁止将其称为时间已认证的交易信号。补充的汇率来源差异见[timestamp-evidence.md](timestamp-evidence.md)。

### 2026-11-04 补充核查：平台存在 WTI 价格历史

官网 EVO 已授权环境的原始能源目录包含 EN0002967（期货结算价:WTI原油，NYMEX，日频，目录覆盖1999-08-26至2026-05-06）和 EN0075096（EIA WTI 现货，日频，目录覆盖1986-01-02至2026-04-27），均通过 get_macro_en 获取。先取得2025-01-02至2025-01-10的7条结算价样本，再逐年下载2018年预热与2019—2025年研究数据，并核对查询日志、重复记录和覆盖。检验期727个目标合约行情日中722个进入分析；匹配成功不代表独立交易所日历已经认证。

此结果纠正了只查看国内期货合约目录带来的遗漏：没有 NYMEX 合约目录，不等于平台没有 WTI 价格指标。宏观序列仅含 symbol、period_date、data_value，不能据此认证历史发布时刻，也不能恢复逐日 CL 合约身份和换月规则。平台取数可用与可执行交易信号验收必须分开。

新研究保留2019—2022训练、2023—2025检验。主研究为平台WTI结算价指标到SC的条件性回放，平台EIA现货另作固定对照；两个版本独立报告，不按结果选优。日期后等待两天只作为显式假设，另检查额外1天和3天延迟。输出必须标为假设研究，不声称“彻底消除未来信息”。Databento不再是必需步骤。

## 可进入正式研究的最低证据

先拿到一组实际外盘—国内商品关系的数据说明与原始记录，再冻结研究。至少保留：

| 部分 | 需核实的内容 |
|---|---|
| 外盘商品 | 实际合约、交易所、频率、价格口径、观测时刻及 IANA 时区或明确偏移 |
| 信息可用时间 | 收盘或发布时刻、供应商延迟、平台入库时刻的定义及可核对记录 |
| 汇率 | 币对、报价方向、取价时点、可用时刻、时区和修订规则 |
| 国内可交易窗口 | 实际交易日历或行情 bar，夜盘交易日归属、节假日与首个可成交时点 |
| 原始留存 | 授权来源、查询条件、获取时间、原始文件散列和时点抽查记录 |

不要用股票或 ETF 替换外盘商品合约，也不要仅为跑通程序改用另一家供应商。用户确认新数据来源后可以重新检查，但来源变化和研究范围变化要显式记录。

无分钟外盘时，可按原任务约定先提出日频隔夜范围并等待难度系数重新确认；这不免除日频记录的实际可用时间核验。仅有日期时，可写出假设性时点敏感性分析，但必须标为假设研究，不能成为“已验证可执行信号”的证据。
