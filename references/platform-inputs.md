# PandaData 原始数据转换

Python 3.11及以上。在已授权的数据环境采集文件，下载后用 `scripts/platform_inputs.py` 转换；这个脚本不联网、不读取账户资料。

| 文件 | 必需字段 |
|---|---|
| SC具体合约日线 | date,symbol,day_session_open,close,limit_up,limit_down |
| 单个WTI宏观指标 | symbol,period_date,data_value |
| 汇率 | date,USD_CNY |

日期格式为YYYYMMDD，国内代码为SCyymm.INE。必须保留各合约完整预热行情，再按决策月+2选合约；不能先只留目标月再算滞后收益，不能把主连当具体合约。重复日期或重复合约/日期会报错。没有day_session_open时直接报错，不拿含夜盘的open替代。

主研究指标EN0002967是NYMEX WTI结算价，平台未给逐日合约编号和换月规则。EN0075096是EIA WTI日频现货，可作独立对照，不是CL期货。两个来源必须分开运行，不按事后表现择优。目录覆盖与实际查询覆盖要分别记录。

外盘价格特征为相邻值之差除以max(abs(前值),20美元)，不是外盘持仓收益；负值和零值保留。USD_CNY要求正值，特征为比值减1。两者观测间隔超过7日时不计算；缺失值不补齐，不跨缺失记录计算。日期之后两天的00:00 UTC是人为等待假设，`--delay-days 3`或5用于预先设定的延迟敏感性。任何配置都不能把假设变成历史可用时间证明。

国内窗口为08:55决策、09:00日盘开盘、15:00收盘。同一合约前两个真实报价日的收盘比值提供国内滞后特征，前次收盘超过10日视为过期。上一报价日18:00为国内滞后特征的假设可用时刻。开盘达到涨跌停、日盘价格缺失或滞后数据不足的窗口被列入排除清单；仍不能据此证明真实成交可达、流动性充分。

输出domestic.csv、events.csv、fx.csv及input-audit.json。所有时间来源固定为assumed；不接受命令行将其改成已认证来源。原始文件校验值和排除日期保留在审计文件中。输出覆盖率只对已取得的数据负责，需另外核对交易日历和源数据是否截断。不同年份的文件不得重叠拼接，也不静默去重。
